# Machine Learning 

This repository contains my Machine Learning algorithms implementations.

## Algorithms Implemented

### 1. Classification
- Dataset: Social Network Ads
- Algorithm: Classification models
- Target: Predict whether a user purchases a product.

### 2. Clustering
- Dataset: Mall Customers
- Algorithms: K-Means, Agglomerative Clustering, and DBSCAN
- Objective: Group customers based on their characteristics.

### 3. Boosting
- Dataset: Insurance
- Algorithms: AdaBoost, Gradient Boosting, and HistGradientBoosting
- Objective: Predict medical insurance charges.
